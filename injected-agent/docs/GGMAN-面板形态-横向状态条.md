# 面板形态改造：横向状态条 + 贴合客户端边缘

日期：2026-11-25
代码：`dll/ggman_core.c` → `dll/build/ggman_core.dll`（281.5 KB）
实测：注入 renderer，客户端 (320,160)–(1600,880)，状态条 **520×36 @ (320,844)**，左下角 0px 贴合

---

## 1. 形态：从竖卡片改成横向状态条

```
┌──────────────────────────────────────────────────────────────────────────┐
│ G  None │ 360安全卫士#43899 Lv.11 · 未定级  情报 0 人 ·（无）        ▣  × │
└──────────────────────────────────────────────────────────────────────────┘
```

| 区段 | 内容 |
|---|---|
| `G` | 品牌标识（青色） |
| 阶段 | `None` / `Lobby` / `ChampSelect`，选人时追加 `剩 23 秒`，排队时追加 `排队 1:20` |
| 主体 | 召唤师名 + 等级 · 段位 · 情报进度 · 上次动作 / 秒退建议 |
| `▣` | 展开完整面板（600×372 四页） |
| `×` | 隐藏（F8 再唤出） |

尺寸 **520 × 36**，只占客户端面积 **2.0%**（原 600×372 是 24%，272×92 是 4.4%）。

## 2. 贴合：0px 贴住客户端左下边缘

- 锚点直接取客户端客户区：`x = client.left`，`y = client.bottom - 36` → **左/下间隙实测 0px**
- 圆角从 12 收到 **6**，进一步像客户端自带的状态栏
- 客户端移动/缩放时跟着走（WinEvent + 16ms 追赶），客户端最小化自动隐藏
- 也可以拖走并记忆位置（`ui_dx/ui_dy`），写 `-1` 恢复默认贴合

## 3. 顿滞感处理

| 手段 | 说明 |
|---|---|
| WinEvent 位置事件 | 客户端移动的瞬间就收到 `EVENT_OBJECT_LOCATIONCHANGE`，立刻重算锚点 |
| **16ms 追赶定时器** | 事件后再保持 400ms 的 60fps 跟随，覆盖拖动中的零散事件 |
| 只在变化时 SetWindowPos | 位置没变完全不调用，避免每帧无谓重排 |
| 移动期间不重绘内容 | 只挪窗口，`g_dirty` 为空就不 InvalidateRect |

**实测**（用 SetWindowPos 以 ~600px/s 模拟拖动客户端 60 帧）：

```
frames 60   mean err 0.0 px   max 0 px
```

即条子与客户端边缘**逐帧对齐**，没有可测的滞后。

## 4. 交互（全部保留）

| 操作 | 效果 |
|---|---|
| 点条子空白处 | 展开完整面板（拖动超过 3px 则视为拖动） |
| 拖条子 | 移动并记忆位置 |
| `▣` | 紧凑 ⇄ 完整 |
| `×` / F8 | 隐藏 / 唤出 |
| 面板外的点击 | 穿透给客户端 |
| 循环卡住 >2s | 整窗自动穿透（不会吞点击） |
| 循环卡住 >4s | watchdog 自动隐藏面板 |
