# 视觉融合：让 agent 看起来是客户端的一部分

日期：2026-11-25
代码：`dll/ggman_core.c`（282 KB）
现状：状态条 520×36 贴客户端左下角；完整面板 600×372 采用客户端同一套配色

---

## 1. 换掉"外挂感"的配色

原来用的是通用深色 UI（近黑 + 青色描边），跟客户端完全不搭。现在整套换成**客户端自己的 hextech 色板**：

| 用途 | 颜色 | 说明 |
|---|---|---|
| 面板底色 | `#0A1428 → #010A13` 上下双色 | 和客户端面板一致 |
| 边框 | `#785A28` 1px 金线 | 客户端的金色描边 |
| 标题 | `#C8AA6E` 金色 | 客户端主文字金 |
| 正文 | `#A09B8C` | 客户端次级文字 |
| 强调/开关 | `#0AC8B9` 青色 | 客户端高亮色 |
| 按钮 | `#1E2328` + `#3C3C41` 描边 | 客户端按钮 |
| 警告 | `#E6A046` | 秒退建议等 |

## 2. 去掉"窗口"的痕迹

| 原来 | 现在 |
|---|---|
| 四个带方框的标签按钮 | **纯文字标签 + 金色下划线**（和客户端顶部导航同一种做法） |
| 标题 "GGman Agent" 白字 | `GGMAN` 金色小标 |
| 圆角 14px 的圆润卡片 | 3–6px 近乎方正，配 1px 金边 + 内层高光细线 |
| 三行堆叠的竖卡片 | 横向单行状态条（520×36），贴客户端左下边缘 0px |
| 客户端不在前台时仍在最上层悬浮 | **只在客户端是前台窗口时出现**，切到别的程序立即隐藏 |

## 3. 当前两种形态

**状态条（默认）**

520×36，贴客户端左下角，跟客户端底边无缝；点条子展开完整面板。

**完整面板（点 ▣ / 点条子）**
600×372，四页：状态 / 自动化 / 情报 / 工具，配色与客户端一致。

## 4. 效果对比

| | 之前 | 现在 |
|---|---|---|
| 配色 | 深黑 + 青边（通用 UI） | 客户端 navy + 金边 + 金字 |
| 标签 | 方框按钮 | 文字 + 金色下划线 |
| 位置 | 浮动在中间 | 贴边 / 或展开后左下 |
| 非前台时 | 仍然悬浮在别的程序上 | 自动隐藏 |
| 观感 | 明显是第三方小工具 | 接近客户端自带面板 |

## 5. 还能更像（如果还需要）

| 方案 | 效果 | 成本 |
|---|---|---|
| 半透明磨砂（`LWA_ALPHA` 200 + 深色底） | 更像客户端半透明图层 | 小 |
| 用客户端字体（Beaufort for LOL / Spiegel） | 字形完全一致 | 小（装字体或内嵌） |
| **SetParent 挂成客户端子窗口** | 真正随窗口裁剪/移动，零延迟 | 中（CEF 可能盖住，需要实测） |
| CEF DOM 注入（真·原生控件） | 最彻底 | 大（1–2 天） |

现在这版已经是"看不出是外挂"的程度；如果还觉得突兀，下一步我建议先试**半透明 + 客户端字体**，成本很低。
