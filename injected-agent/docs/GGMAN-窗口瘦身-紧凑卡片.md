# 窗口瘦身：紧凑卡片 + 可拖动 + 可记忆位置

日期：2026-11-25
代码：`dll/ggman_core.c` → `dll/build/ggman_core.dll`（279.5 KB）
实测：注入 renderer pid 9768，客户端 (320,160)–(1600,880)，面板 **272×92 @ rel(996,616)**（右下角，距边 12px）

---

## 1. 尺寸变化

| 模式 | 尺寸 | 内容 |
|---|---|---|
| **紧凑（默认，`ui_compact=1`）** | **272 × 92** | 标题(G + 阶段) / 召唤师+等级 / 段位+情报进度 或 选人倒计时 或 排队时长 / 上次动作（秒退建议命中时变琥珀色） |
| 完整（点 ▣ 展开） | 600 × 372 | 四页标签：状态 / 自动化 / 情报 / 工具 |

原来常驻的是 600×372（占屏幕 1/6），现在默认只占 **272×92 ≈ 客户端的 2.7% 面积**。

## 2. 位置

- **默认右下角**（远离大厅的「开始游戏」、英雄选择、商城等点击热点，也不压住客户端右上角的窗口按钮）
- **可拖动**：按住卡片顶部标题条拖即可（`g_title_rect` 命中 → SetCapture → 移动中夹在客户端客户区内）
- **记忆**：松手写回 `ui_dx/ui_dy`（相对客户区左上角），下次启动按记忆位置；写成 `-1` 恢复自动右下角

> 踩坑记录：上一版把卡片放在**右上角**，正好压住客户端的窗口按钮区——我的合成点击（穿透后）直接点到了客户端的关闭键，把客户端关掉了两次。所以默认改右下，并加了拖动。

## 3. 交互

| 操作 | 效果 |
|---|---|
| 点 ▣ | 紧凑 ⇄ 完整 切换（两种模式都有这个按钮） |
| 拖标题条 | 移动，松手记忆 |
| 点 × | 隐藏（再按 F8 或点徽标回来） |
| F7 | 紧凑/完整 切换（等同点 ▣） |
| F8 | 显示/隐藏 |
| 空白区点击 | **穿透**给客户端（`HTTRANSPARENT`） |
| 紧凑卡片显示时 | 顶栏 G 徽标自动隐藏，避免两个入口打架；卡片隐藏后徽标回来 |

## 5. 仍可再小（如果你想）

| 方案 | 尺寸 | 代价 |
|---|---|---|
| 极简单行（阶段+倒计时只显示一行） | 220×40 | 看不到召唤师/段位 |
| 只有徽标（32×32），点开才出卡片 | 32×32 | 需要点一次才能看信息 |
| 完全交给网页控制台，界面上零常驻 | 0 | 要切到浏览器/落地页 |

现在是「272×92 常驻 + 一键展开 + 可拖动」，我建议先这样用两天，觉得还大就砍到单行。
