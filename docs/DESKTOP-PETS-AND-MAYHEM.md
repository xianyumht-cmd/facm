# FACM 桌面宠物与海斗排行榜

## 桌面宠物

控制面板主题和桌面宠物外观是两个独立设置：

```ini
ThemeId=glass-blue
PetStyleId=jelly-blue
```

桌宠可在所有显示器的可见桌面范围内自由拖动，松开后保存准确坐标，不再自动吸附左右边缘。只有保存坐标已经完全离开全部显示器时，程序才会在下次启动时恢复到主屏幕可见位置。

内置桌宠：蓝莓啵啵、奶油猫、落日狐、薄荷机器人、紫雾幽灵、柠檬团子、赤焰幼龙、星愿精灵、像素机兵、云朵兔。

实现使用 WinForms 无边框顶层窗口、非矩形 Region、GDI+ 矢量绘制和定时帧动画。没有复制外部桌宠项目的图像或代码。

## 海斗排行榜

入口：控制面板底部“海斗排行”，或托盘右键菜单“海斗排行榜”。

支持输入英雄官方中文名、英文名和常用别名，展示：

- 当前版本与胜率排名
- 胜率、选择率和梯队
- buff / debuff
- 推荐出装
- 技能加点
- 推荐强化符文
- 当前版本总体胜率前十

数据源优先使用 OP.GG 官方 MCP，页面数据作为低频回退。查询由用户主动触发，结果缓存 10 分钟，并在界面保留 OP.GG 来源链接。
