# FACM 3.5.19 / 4.x 清理清单

日期：2026-09-05  
主产品线：FACM 3.5.19（WinForms / net48 / 轻量单 EXE）  
参考产品线：FACM 4.x（只作为最佳实践来源，完成后退出默认工作树）  
关联：Draft PR #241、`docs/3.5.19-4.0.6-BACKPORT-AUDIT.md`、`docs/3.5.19-P1-BACKPORT-STATUS-2026-09-05.md`

## 1. 清理原则

本清单用于在 3.5.19 回灌通过实机 Gate 后，机械地删除默认工作树中的 4.x-only 项目、构建/迁移链、探针、证据和历史操作文档。

“删除 4.x”首先指**删除当前工作树里的 4.x-only 文件**，不是重写 Git 历史。Release、tag、远端临时 branch 属于第二层破坏性清理，必须在 3.5.19 主线稳定后用单独的显式列表执行。

分类：

- **RETAIN**：3.5.19 当前构建、运行、更新、测试仍依赖。
- **DELETE AFTER GATE**：已证明不属于未来 3.5.19/GGman 主线，实机 Gate 后删除。
- **MIGRATE / CONSOLIDATE**：保留文件名/职责，但把当前事实改成 3.5.19。
- **REVIEW**：仍需最后一次引用扫描，不能凭名字删除。
