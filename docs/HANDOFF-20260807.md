## 最新实现（Build #248）

### 1. Desktop Homunculus Windows 透明窗口兼容

已核对上游 `not-elm/desktop-homunculus`：Windows 代码强制使用 `CompositeAlphaMode::PreMultiplied`。用户机器实际 Surface 只返回 `[Opaque]`，因此这次崩溃不是拖动 FACM 悬浮球导致，而是 Desktop Homunculus/wgpu 在透明 Surface 配置阶段崩溃。

FACM 当前处理：

- Windows 启动 Desktop Homunculus 时默认设置 `WGPU_BACKEND=dx12`，绕开用户机器触发错误的 Vulkan 路径。
- 可通过环境变量 `FACM_DESKTOP_PET_WGPU_BACKEND` 覆盖后端，便于后续诊断。
- 启动期间检测 `Desktop Homunculus - Error` / 未响应窗口；出现异常立即清理失败进程。
- 已安装引擎启动失败时不再无意义重复安装 MSI。
- 桌宠成功启用后增加健康检查；本地 API 连续失效时自动恢复默认悬浮球并停止桌宠事件订阅。
- 安装、启动、恢复或运行中崩溃均不得造成 FACM 无桌面入口。

注意：GitHub Windows CI 无法模拟用户 GTX/驱动/桌面合成环境，因此 DX12 是否彻底解决该机器的 `PreMultiplied` 错误必须由用户实际运行 Build #248 验证。如果仍崩溃，下一步应构建/维护 Desktop Homunculus Windows 兼容补丁，而不是改成 Opaque 牺牲透明桌宠。

### 2. 默认悬浮球视觉修复

- 去掉旧 `TransparencyKey=Magenta` 色键透明方式，避免紫粉色边缘。
- 改为圆形窗口 Region，球体内部重新绘制为蓝/青/深蓝玻璃能量球。
- 重做 halo、rim、高光、核心和轨道线，不再使用紫粉边缘色。
- `--floating-ball-test` 会检查：窗口 Region 存在、没有 TransparencyKey、蓝色内容足够、紫粉色像素不得超过阈值。

### 3. Mayhem 强化排行图片队列

- 排行顺序直接读取当前英雄 ARAM Mayhem 排行页。
- 展示前 5 个强化，卡片文字只保留 `#1 / #2 ... + 胜率`，不再显示英文强化名或字母占位块。
- 图标直接从 League 当前静态资源的 Cherry / Kiwi 强化目录并行探测；Mayhem 专属如 `Final Form`、`Upgrade Infinity Edge` 使用 Kiwi 资源，Arena 通用强化使用 Cherry 资源。
- 内部文件名别名已处理，例如 `Upgrade Infinity Edge -> upgradeie`。
- 不再先下载大型强化 JSON，减少查询耗时。
- CI 要求前 5 个强化图标 URL 全部存在，并逐张下载、解码为 Bitmap；任一图片失败即禁止打包。
