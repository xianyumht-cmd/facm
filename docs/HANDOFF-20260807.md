### 便携数据目录

用户要求 FACM 运行产生的数据/缓存尽量放在 FACM 程序目录旁，避免桌宠继续向 C 盘用户目录写数据。

已实现：

- 设置：`FACM\settings.ini`
- UI 文本：`FACM\ui-text.ini`
- 日志：`FACM\logs\`
- 工具/更新：`FACM\runtime\`
- 旧 Sprite：`FACM\runtime\animal-sprites\`
- 海斗图片缓存：`FACM\runtime\cache\mayhem-images\`
- VPet 资源/动画缓存：`FACM\runtime\pethost\Assets` / `Cache`

PetHost 由 FACM 启动时显式传 `--data-root <FACM\runtime\pethost>`。

旧 `%LOCALAPPDATA%\FACM\PetHost` 如存在，会首次启动时复制到新便携目录，逐文件检查长度后再尝试删除旧目录。迁移失败不阻止启动，会在新目录重新准备资源。

海斗图片缓存已移除 Windows TEMP 回退；FACM 目录不可写时只使用内存缓存，不再向系统临时目录落盘。

静态检查剩余 `LocalApplicationData` 引用只包括：

- 旧 VPet 数据迁移源；
- 旧 settings/ui-text 一次性兼容迁移源；
- 已退出正式路线的 Desktop Homunculus 历史安装位置探测/测试。

当前 VPet 正式运行不再把新的资源/缓存写 `%LOCALAPPDATA%`。
