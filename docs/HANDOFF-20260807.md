## VPet Core / 动画版本固定策略

运行代码固定：

- NuGet：`VPet-Simulator.Core` 1.1.0.66；
- NuGet 发布日：2026-05-19；
- 目标：.NET 8 Windows。

VPet 当前仓库 2026-08 的源码已经把 `IController.RePostionActive` 改名为 `RePositionActive`，而 NuGet 1.1.0.66 的真实编译接口仍是历史拼写 `RePostionActive`。CI #297 首次真实暴露了这个版本差异，之后宿主已兼容两种属性名。

因此动画资源也**不追 8 月最新仓库**，改为固定到 2026-05-19 当天的默认动画更新提交：

`ac77ba144ed39f61624d93542c008b38be4d85aa`

该提交里的 `IController` 与 NuGet 1.1.0.66 的编译接口一致，作为同代资源快照更稳。

首次启用 VPet 桌宠时按需缓存：

- `vup.lps`
- `vup/Default/`
- `vup/IDEL/`
- `vup/MOVE/`
- `vup/Raise/`
- `vup/StartUP/`
- `vup/Touch_Body/`
- `vup/Touch_Head/`

缓存目录：

`%LOCALAPPDATA%\FACM\PetHost\Assets\vpet-ac77ba14\`

下载保护：

- 先读官方 Git tree；
- 校验必需 `vup.lps`；
- 文件数异常偏少直接失败；
- 总大小为 0 或超过 700MB 直接失败；
- 最多 8 并发；
- 随机 `.partial-*` staging；
- 全部完成并写 marker 后才原子改为正式缓存目录；
- 中断不会留下“半套资源却被判定成功”的缓存。
