## Build #249 已实现

### Desktop Homunculus 兼容

- 已确认崩溃来自上游 Windows 强制 `CompositeAlphaMode::PreMultiplied`，不是 FACM 拖动悬浮球。
- Windows 启动 Desktop Homunculus 时默认设置 `WGPU_BACKEND=dx12`，尝试绕开用户机器触发错误的 Vulkan 路径。
- 可用环境变量 `FACM_DESKTOP_PET_WGPU_BACKEND` 覆盖后端。
- 启动期间检测 Desktop Homunculus 错误窗口/未响应窗口并清理失败进程。
- 桌宠成功后持续健康检查；API 连续失效自动恢复默认悬浮球。
- 已安装引擎启动失败时不再重复安装 MSI。
- GitHub CI 无法复现用户显卡/驱动/桌面合成环境，因此 DX12 是否解决 `PreMultiplied` 崩溃必须由用户实机验证；若仍失败，下一步进入 Desktop Homunculus 自定义 Windows 补丁构建路线，不能改成 Opaque 破坏透明效果。

### 默认悬浮球视觉

- 去掉 `TransparencyKey=Magenta`。
- 改为圆形窗口 Region。
- 重绘蓝/青/深蓝玻璃球、高光、轨道、核心和边缘光。
- smoke test 明确检查无色键透明、圆形 Region、足够蓝色内容以及紫粉色像素阈值。

### Mayhem 强化排行图片

- 英雄排行页负责前 5 强化顺序和胜率。
- 卡片只显示排行/胜率，不再显示英文强化名或单字母占位。
- 真实图标从 League 当前 Cherry / Kiwi 静态强化资源目录并行定位。
- Mayhem 专属强化使用 Kiwi，例如 `Final Form -> finalform_small.png`、`Upgrade Infinity Edge -> upgradeie_small.png`。
- 通用强化使用 Cherry，例如 `Mystic Punch`、`Outlaw's Grit`、`Goredrink`。
- CI 要求 5 个强化图标全部逐张下载并解码成功，否则禁止打包。
