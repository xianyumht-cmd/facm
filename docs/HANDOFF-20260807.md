## 用户最新明确要求

### 1. 默认必须有高级 3D 悬浮球

当前版本 `MainForm` 自身是 `1x1`、透明、放到屏幕外，启动后如果第三方桌宠没有成功恢复，桌面上完全没有 FACM 悬浮入口。这不符合要求。

目标：

- FACM 启动后**始终立即显示一个内置的高级 3D 悬浮球**。
- 默认悬浮球不依赖桌宠资源包、不依赖外部引擎安装。
- 默认悬浮球可在桌面任意位置自由拖动、停放并持久化坐标。
- 点击默认悬浮球打开控制面板。
- 右键可打开常用菜单。
- 控制面板的 10 套主题只影响控制面板，不影响默认悬浮球。
- 当用户主动选择“桌面宠物”后，才下载桌宠资源和引擎；桌宠成功启动后替换默认悬浮球。
- 如果桌宠安装、下载、启动或恢复失败，必须自动保留/恢复默认悬浮球，绝不能出现“程序运行但桌面没有入口”的状态。
- 用户可接受程序/资源总量约 100 MB，不能再为了控制体积而做过于简陋的实现。

验收标准：

1. 全新目录首次启动、没有任何桌宠组件时，3 秒内看到默认 3D 悬浮球。
2. 拖到桌面任意位置，退出后重启位置保持。
3. 点击能打开控制面板。
4. 桌宠下载失败后默认悬浮球仍然存在且可用。
5. 桌宠成功启用后再隐藏/替换默认悬浮球。

### 2. 修复桌宠安装后找不到程序的问题

用户实际日志：

```text
2026-08-07 11:03:21.169 [ERROR] Open-source 3D pet activation failed
System.IO.FileNotFoundException: 安装完成，但没有找到 desktop-homunculus.exe。
文件名:“...\\runtime\\desktop-homunculus\\desktop-homunculus-0.1.0-alpha.6-x64.msi”
```

已确认问题不是简单“模型坏了”，而是 FACM 安装 MSI 后对安装目录/可执行文件名的探测不可靠。

需要继续完成：

- 核对 `not-elm/desktop-homunculus` 当前 Windows MSI 的真实安装目录、真实 exe 名和注册信息。
- 不要只硬编码 `desktop-homunculus.exe`。
- 安装完成后从以下来源联合定位：
  - MSI / 卸载注册表 InstallLocation / DisplayIcon / UninstallString；
  - `Program Files` / `Program Files (x86)` / LocalAppData；
  - 开始菜单快捷方式目标；
  - 安装后产生的进程路径；
  - 必要时递归查找与产品名匹配的 `.exe`。
- 找到后实际启动，再等待本机服务/API就绪；不能“msiexec 返回 0”就视为完成。
- 安装/启动失败时向普通用户只显示简洁提示，详细技术信息写日志。
- 保留取消操作。
- 对上游真实安装结果增加可重复验证。

### 3. 海斗排行榜改成中文图片卡片，不要纯文字表格

当前 `MayhemLookupForm` 仍然主要由 `Label`、`TextBox`、`DataGridView` 组成，属于文字界面，不符合用户截图后的要求。

目标界面：

- 输入框仍可使用英雄中文名、英文名、别名。
- 查询结果主体改为**一张完整图片卡片**，用户看到的查询结果尽量不使用纯文字控件堆叠。
- 图片卡片内使用小图标和真实图片展示：
  - 英雄头像/立绘；
  - 当前版本、梯队、名次、胜率、选用率；
  - buff / debuff；
  - 技能 Q/W/E/R 图标与加点顺序；
  - 装备图标；
  - 强化符文/强化图标；
  - 当前版本总体胜率前十，每行带英雄头像、小图标、排名和胜率。
- 界面整体中文化，不向普通用户展示“独立排行源”“避免伪造空字段”“API/MCP”等开发说明。
- 结果卡片应支持复制/保存图片（至少内部生成 Bitmap；可提供“保存图片”按钮）。
- 查询中的进度/取消可以保留普通控件，但**最终结果区域是图片**。

### 4. 海斗榜数据源要求

用户最新要求：“用现成的官方接口”。下一会话需要重新核实现有公开/官方数据接口，不要延续错误假设。

当前代码的情况：

- 之前使用 OP.GG 页面数据 + 另一个排行数据源拼接。
- 用户希望尽可能改成现成官方接口，并完整中文展示。
- 开发时必须先确认接口在 2026-08-07 当前是否真实可用、是否返回 Mayhem 所需字段，再编码。
- 不得因为某字段取不到就伪造或把来源写成 OP.GG。
- 如果某类数据官方接口确实不提供，需要在实现方案内部明确回退，但普通用户结果页不要出现开发者式解释。

需要的最终数据字段：

- 英雄当前版本海克斯大乱斗胜率排名；
- 当前版本 buff / debuff；
- 当前版本出装；
- 当前版本技能加点；
- 当前版本总体胜率排行榜前十；
- 英雄头像、技能图标、装备图标、强化图标等图片 URL/资源。

性能要求：

- 查询不能再长时间“无响应”。
- 多来源请求并行。
- 总超时控制在约 5–8 秒。
- 关闭窗口或点取消立即取消请求。
- 图片下载也应并行，并做内存/磁盘缓存。
- 查询结果缓存约 10 分钟可继续保留。
