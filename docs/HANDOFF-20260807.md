### `ui-text.ini` 全局 UI 文案配置

用户最终决定不再逐条修改/删除“面向开发者、项目方、技术架构”等描述，而是永久解决：**FACM 相关显示文字统一交给 `ui-text.ini` 配置。**

当前实现：

- 配置文件：`FACM\ui-text.ini`，与 `FACM.exe` 同级；
- `[Text]`：程序名、控制中心、清理、工具、模式、更新、日志、主题、桌宠、排行榜、目录、状态等常用文字；
- `[Replace]`：全局兜底，使用 `原文=新文` 替换没有独立键的固定界面文字，右侧可留空以隐藏；
- 运行中监控配置文件变化，保存后自动重新读取，不需要重新编译；
- WinForms 窗口标题、Label/Button、菜单/托盘菜单、列表、表头、Tooltip、普通 MessageBox 等已接入统一文字层；
- 启动阶段弹窗也直接读取 `ui-text.ini`；
- PetHost 启动时 FACM 传入同一份 `ui-text.ini` 路径，桌宠首次加载/状态提示也使用该配置；
- 用户输入、查询结果业务数据、在线公告正文、第三方动态数据不做强制全局替换，避免误改实际数据；
- 升级时新增 `[Text]` 键会自动补充，不覆盖用户已有值。

后续如果用户不喜欢任何固定文案，优先让用户直接改 `ui-text.ini`，不要再通过代码逐条删词。

### 便携数据目录

用户要求 FACM 运行产生的数据/缓存尽量放在 FACM 程序目录旁，避免桌宠继续向 C 盘用户目录写数据。

已实现：

- 设置：`FACM\settings.ini`
- UI 文本：`FACM\ui-text.ini`
- 日志：`FACM\logs\`
- 工具/更新：`FACM\runtime\`
- 旧 Sprite：`FACM\runtime\animal-sprites\`
- 海斗图片缓存：`FACM\runtime\cache\mayhem-images\`
- VPet 资源/动画缓存：`FACM\runtime\pethost\Assets` / `Cache`

PetHost 由 FACM 启动时显式传 `--data-root <FACM\runtime\pethost>`。

旧 `%LOCALAPPDATA%\FACM\PetHost` 如存在，会首次启动时复制到新便携目录，逐文件检查长度后再尝试删除旧目录。迁移失败不阻止启动，会在新目录重新准备资源。

海斗图片缓存已移除 Windows TEMP 回退；FACM 目录不可写时只使用内存缓存，不再向系统临时目录落盘。

静态检查剩余 `LocalApplicationData` 引用只包括：

- 旧 VPet 数据迁移源；
- 旧 settings/ui-text 一次性兼容迁移源；
- 已退出正式路线的 Desktop Homunculus 历史安装位置探测/测试。

当前 VPet 正式运行不再把新的资源/缓存写 `%LOCALAPPDATA%`。

## 发布包默认配置

用户计划把 `settings.ini` 直接放到发布压缩包根目录，与 `FACM.exe` 同级。

`AppSettings` 当前读取以下 8 个键：

```ini
BallX=-2147483648
BallY=-2147483648
GamePath=
AutoUpdateEnabled=True
LastAnnouncementId=
ThemeId=aurora-night
PetStyleId=vpet
AnimalPetEnabled=True
```

发布建议：

- `BallX/BallY=-2147483648`：表示未保存过位置，让每台电脑按自己的主屏幕选择默认悬浮位置，不要把开发机的 `558/115` 等实际坐标带进发布包；
- `GamePath=`：保持空，让用户自动识别/选择；
- `AutoUpdateEnabled=True`：默认启用更新检查；
- `LastAnnouncementId=`：发布包保持空；
- `ThemeId=aurora-night`：有效主题 ID，对应“极光夜幕”；
- `PetStyleId=vpet` + `AnimalPetEnabled=True`：**首次启动 FACM 会自动启动 PetHost，并在 `runtime\pethost` 没有完整资源时联网自动下载/补齐 VPet 桌宠资源，随后生成动作缓存并显示桌宠。**

如果是覆盖升级且 `runtime\pethost` 已有完整资源，则不会整批重复下载，只会按现有校验/续传逻辑补缺失文件。

发布包推荐根目录：

```text
FACM\
├─ FACM.exe
├─ settings.ini
├─ ui-text.ini        # 可选：随包提供用户想要的默认文案
├─ PetHost\
└─ ...
```
