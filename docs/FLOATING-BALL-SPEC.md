# FACM 3.0 悬浮入口与控制中心规格

- 空闲状态显示 68×68 悬浮入口，不创建传统任务栏主窗口。
- 悬浮入口始终置顶，支持托盘恢复、右键菜单、拖动和左右边缘吸附。
- 单击后展开 408×594 控制中心，窗口自动显示在悬浮入口内侧并限制在当前屏幕工作区。
- 控制中心采用统一深色视觉、圆角卡片、状态栏和管理员权限标识。
- 工作目录、清理环境、内置工具、操作日志和程序信息采用分区卡片布局。
- 清理环境使用独立 720×540 预览窗口，展示完整路径、类别、状态和估算大小。
- 控制中心失去焦点时自动收起；系统选择器、确认框与工具菜单打开期间不会误关。
- 主程序默认 `asInvoker`；只有用户主动确认清理系统目录时才通过 `runas` 按需提权。
- 提权后的实例自动恢复控制中心并继续清理流程，不要求用户重复点击。
