## 2.0 重写原则

1. 不从旧 EXE 提取或复用二进制组件。
2. 不捆绑、释放或启动第三方 EXE。
3. 不联网，不包含自动更新器。
4. 所有删除目标由固定白名单产生。
5. 扫描、展示、确认、删除四个阶段分离。
6. 保留本地日志，便于复核每次操作。
7. 构建可复现；签名仅在发布流水线最后一步执行。
