# FACM 3.0 清理规格

## 配置来源

清理目标只由 `src/FACM/Configuration/CleanupProfile.cs` 中的编译期配置生成。最终用户不能在界面中输入任意删除路径。

任何 `REPLACE_...` 占位符未替换时，清理功能保持禁用。

## 候选目标

程序最多生成以下几类候选项：

1. `%ProgramFiles%\<配置文件夹名>`
2. `%ProgramData%\<配置文件夹名>`
3. `<安装根目录>\<配置容器相对路径>` 的直接子文件和直接子文件夹，但跳过配置的保留目录，默认 `DATA`
4. `<安装根目录>` 下两个开发者指定的额外相对文件夹
5. 开发者指定日志目录顶层的 `*.log`

不会执行整盘模糊搜索，也不会删除名称相似但不属于上述规则的路径。

## 安装目录识别

程序按以下顺序解析安装根目录：

1. 从开发者配置的相关运行进程读取可执行文件路径。
2. 从 Windows 卸载项中读取匹配显示名称关键词的 `InstallLocation`、`DisplayIcon` 等路径。
3. 自动识别失败后，由用户通过系统文件夹选择器选择目录。
4. 在有限深度内查找开发者配置的标记文件夹，并把其上级目录作为安装根目录。

注册表只读，不写入第三方项目。

## 执行保护

- 相关进程仍在运行时拒绝清理。
- 系统目录操作仅在用户主动点击清理后按需请求管理员权限。
- 先扫描和统计，再显示完整路径预览。
- 用户确认后，删除前再次验证每个目标所属规则。
- 动态目标必须保持在识别出的安装根目录内。
- 保留目录不会加入删除计划。
- 检测到 junction、符号链接或其他重解析点时阻止整个相关目标。
- 不停止服务、不结束进程、不创建计划任务、不执行隐藏命令。
- 每个成功、失败和阻止结果写入本地日志。

## 日志

FACM 日志位于 `%LocalAppData%\FACM\Logs`，不会上传。
